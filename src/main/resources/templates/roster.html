Your saved learners and tutors, so you can pick them from a list instead of retyping names and emails.

Import from the platform's user export

Upload the file the platform exports — .csv, .xlsx, or .xls all work. It needs a header row with a column containing "name" and a column containing "email". If there's also a "Type" or "Role" column (like the platform's export has), learner/tutor is read straight from it — a value such as "Learner | Tutor" adds that person to both lists automatically.
